# Arab Regional Finance Roundtable 2025

Registration site for the Arab Regional Finance Roundtable 2025, held on 29 April 2025. The roundtable focuses on mobilizing capital for climate sectors in the Arab region.

This repository is that registration site, including Google Sheets registration. It is not a form-builder product.

- Live site: https://arab-finance-form-builder.vercel.app
- Repository: https://github.com/LifeAyush/arab-finance-roundtable

## How to run

You need Node.js and npm.

```sh
git clone https://github.com/LifeAyush/arab-finance-roundtable.git
cd arab-finance-roundtable
npm install
npm run dev
```

`npm run dev` starts the Vite development server and prints a local URL. `npm run build` creates a production build, and `npm run preview` serves that build locally.

## Stack

- Vite
- TypeScript
- React
- Tailwind CSS
- shadcn/ui
